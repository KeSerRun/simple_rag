将以下用户问题拆解为多个**独立的检索子问题**，每个子问题应该是一个完整、自包含的检索查询，能够独立从知识库中检索到有用的信息。

## 拆解原则

1. 把多方面的复杂问题拆成单一焦点的子问题
2. 对比类问题 → 为每个对比对象分别生成子问题
3. 条件筛选类 → 为每个条件生成独立子问题
4. 保持原问题的核心意图，不要偏离太远
5. 子问题用简洁的陈述句或关键词短语，便于检索
6. 一般不超过 5 个子问题

## 示例

用户：Python 和 Go 在并发编程上的优劣对比？
子问题：
Python 并发编程的特点和优势
Go 并发编程的特点和优势
Python 并发编程的局限和性能瓶颈
Go 并发编程的适用场景

## 用户问题

{query}

请直接输出子问题，每行一个，不要编号，不要额外解释。
