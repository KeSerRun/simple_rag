## 核心分层

| 层 | 目录 | 职责 |
|----|------|------|
| **接口层** | `api/` | FastAPI 路由，认证，SSE 流式 |
| **Agent 引擎** | `agent/` | 工具循环（ToolLoop）、状态管理、上下文治理 |
| **工具层** | `agent/tools/` | 14 个注册工具，IRRF 重排检索 |
| **RAG 基础设施** | `rag/` | 向量存储、PDF 解析、评估 |
| **存储层** | `storage/` | JSON 文件持久化 |
| **基础层** | `base/` | 配置、LLM 客户端、日志 |
| **前端** | `web/` | Vue 3 + Naive UI |

## 数据流

```
用户输入
  → 历史加载 (get_history → 超限压缩/截断)
  → system + history + query 组装
  → LLM 调用 → 返回 tool_calls 或最终答案
    └─ 有 tool_calls? → dispatch 执行 → 结果回灌 → 继续 LLM
    └─ 无 tool_calls? → 返回最终答案
  → 保存历史
```

## 配置分层加载

```
config.ini ← 基础配置
  ↓ 叠加
.env ← 环境变量/密钥覆盖
  ↓ 叠加
OS 环境变量 ← 最高优先级
```

详细的配置项说明参见 [基础模块文档](base.md)。

## 核心功能

- **多工作流**：简报、对比、深度研究、自动规划、美股分析
- **工具调用**：知识库检索（RRF 融合）、联网搜索、文档阅读等 14 个工具
- **PDF 解析**：MinerU API（VLM/Lite 模型），支持图片/表格/文本混合
- **上下文治理**：超预算时自动压缩工具结果或截断旧历史
- **中断恢复**：工具迭代达上限后保存状态，回复"继续"恢复
- **管理后台**：配置热更新、向量库管理、检索质量评估
