# Workflow 路由

Agent 在处理用户查询时，首先检测查询是否命中某个 workflow 的领域。如果命中，则**必须严格按照该 workflow 定义的步骤执行**，不得跳过或改变顺序。

**路由规则统一在此文件管理**，每个工作流在下方「路由规则」区定义触发关键词。

## 添加新工作流

1. 在 `workflow/` 下创建 `.md` 文件（如 `xxx.md`），文件内容为分步工作流指令
2. 在此文件「路由规则」区新增一行 `- xxx: 关键词1, 关键词2, ...`
3. 重启后端，路由自动生效

工作流文件名（不含 `.md`）必须与路由规则中的名称一致。
